How a value is decided

Every location runs through the same ordered pipeline against 10,160 official SIRUTA localities. The first rule that matches wins.

  1. Strip the address

    Postal codes, ap. 21, etaj 3, camera 4, nr. and bl. are removed so only a place name can remain.

  2. Exact match

    Compared without diacritics or punctuation, so clujnapoca and CLUJ NAPOCA both resolve to Cluj-Napoca.

  3. Known foreign

    Checked before any guessing, so Olanda is never bent into a similar looking Romanian village.

  4. Fuzzy repair

    Levenshtein distance against every official name, for real typos: Timisora, Sinmartin, Rimnicusarat.

  5. Expand and trim

    Abbreviations and historic qualifiers are resolved: Sf. Gheorghe to Sfântu Gheorghe, Campulung-Muscel to Câmpulung.

  6. Classify the remainder

    Whatever is left is either a real place outside Romania, or not a location at all.

What it refuses to do

Commands

node doctor.js health              index overview, coverage, integrity
node doctor.js normalize           analyse locations, dry run
node doctor.js normalize --apply   write the corrections
node doctor.js report              print this report and rebuild the page
node doctor.js purge-junk          preview the deletions
node doctor.js purge-junk --yes    delete the junk documents

Deletion never happens without --yes. Without it the command prints the count and a sample, then stops.

Reference data: SIRUTA official administrative registry via api.siruta.ro. Job data: peviitor.ro production mirror. Corrections are written as Solr atomic updates, so only location, verified, international and junk are touched.
